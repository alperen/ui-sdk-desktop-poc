Method

The three series come from the same paired measurement session. The compiler-off controls and the compiled React build ran the same 12 interactions in Chromium 158 at 1000 × 700. Warm-ups were excluded. Each sequence included 26 behavior checks.

Render time sums the root Profiler’s actualDuration after the initial mount. Each interaction has its own five-round median. The full-sequence median uses each round’s total. Winners use the precision shown in the table. Small differences can vary between runs.

Input processing and rendering come from production Chrome traces and can overlap. Heap was measured after garbage collection. The first paint opportunity follows the folder double-click. Memoization and component counters ran in a separate diagnostic build, where clock reads affect short timings.
